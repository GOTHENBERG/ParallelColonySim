# ParallelColonySim

План самостоятельной 2D-колониальной симуляции на Bevy/Rust с детерминированным многопоточным ядром.

- [Архитектура, игровая логика и дорожная карта](docs/architecture-and-roadmap.md)
- [Инструменты разработки и открытый процесс](docs/development-tooling.md)
- [Концепция и базовый профиль Phase 0](docs/phase-0-baseline.md)
- [Исходные замеры производительности](docs/performance-baseline-2026-10-10.csv)

Проект ориентируется на жанр colony sim, но не использует исходный код, графику, тексты или другие закрытые материалы RimWorld.
